## Engineering practices

- **Architecture** — Keep application layers and their dependencies explicit, with shared contracts at integration points.
- **User experience** — Build accessibility, localization, and error recovery into the interface.
- **Verification** — Cover business rules with focused tests and check key user flows before release.
